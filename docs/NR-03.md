# NR-03 美术与可读性

给游戏组-虚幻引擎操作。这张卡只有一个要验收的动作。PM 确认这一卡可读之前，不要把制作扩到其他城区。

**仓内规格已入库。实机录像仍等 UE。** 本环境没有装 UE，也没有 PIE 截图或录像。色盲可读和 4 秒灯带用 `sim/steel_tide` 的几何与事件时间核对。概念图不能代替当前构建的录像。

**验证动作：** 在关掉高反射的画面里录下约 4 秒的桥预警，并让两名外形相同的人形机器人在灰度下仍能靠肩章形状分出 A 和 B。

**通过（上机）：** 同一机位有灰盒与这一卡的前后对比；一段预警录像在反射质量关闭后，仍能从灯带推进和警报听出「大约 4 秒后桥接通」；灰度或色盲模拟下，两名同体人形不会被认成同一队。录像来自当前构建，不用概念图代替。

**通过（仓内，本 PR HEAD）：** `PYTHONPATH=sim python3 -m steel_tide nr03 --check` 退出码为 0。它核对代理规格、遮住颜色后的肩章几何，以及警报与灯带同一毫秒开始、4 秒后 `BridgeWarningCompleted` 与桥接通同时发生。这不是实机通过。

## 目标对象

| 对象 | 做什么 |
| --- | --- |
| `NR_Proxy_WetConcrete` | 湿混凝土，粗糙度高，深色。可以有轻微环境反射，但验收时把高反射关掉 |
| `NR_Proxy_EngineeringMachine` | 磨损黄漆，放在港区，当比例参照 |
| `NR_Proxy_Quadruped` | 低伏、四条腿。这是机器人，不是兽。轮廓 id `hydraulic_quadruped` |
| `NR_Proxy_Beast` | 有机兽的体态，轮廓 id `organic_beast`。必须和四足机不同，不能只换颜色 |
| `NR_Proxy_Humanoid_A` 与 `NR_Proxy_Humanoid_B` | 同一套身体 `NR_Body_Humanoid`。A 开口人字肩章 + 左肩灯，B 闭合环 + 右肩灯 |
| `NR_BridgeSpan` 灯带 | 沿跨度的一排灯，在 4 秒内依次点亮 |
| 警报 | 与灯带第一盏同时开始的声音。倒影可以关，灯带和声音不能关 |

环境招牌可以用青蓝和玫红。它们不是队标，不能比肩章更抢。

## 参数

- 预警提前量 4.0 秒，写在 `bridge_warning_seconds`
- `readable_without_reflection` 写在同一份配置里，本卡为 true
- `BridgeWarningStarted`：警报与灯带第一盏同一毫秒开始
- `BridgeLightStripAdvanced`：中间几盏。不改持有者，不计分
- `BridgeWarningCompleted` 与 `BridgeStateChanged`（`connected`）同一毫秒。提前量刚好 4 秒
- 验收时关闭高反射（例如把反射质量降到关，或等价的后期设置）。倒影提前亮只是提案里的表现，不是唯一信号
- 分辨率、画质档、关闭了哪一项反射，全部写进回传
- 两名人形站在同一灯光下。验收时看灰度：遮住颜色后，人字和环仍然可辨

仓内对应命令不产生音频文件，也不产生截图。事件时间就是这一卡的程序验收。

## 步骤

1. 在仓库根目录先跑 `PYTHONPATH=sim python3 -m steel_tide nr03 --check`。不过就不要上机摆代理。
2. 在 NR-01 的同一机位保存一张「只有灰盒」的图。
3. 放上表里的材质代理、兽、四足机和两名同体人形。不要换身体来表示阵营。
4. 触发一次桥预警：灯带用 4 秒走完，警报同时响。跨度可以先保持可走，这张卡不改 NR-02 的胜负。
5. 关掉高反射后再录一遍这 4 秒。
6. 把画面转成灰度或打开色盲模拟，截两名人形的肩章。

## 画面目标

关反射之后，不看水面也能知道桥要接通。灰度里，A 和 B 的人形不会靠「一个偏青、一个偏黄」才能分开。兽和四足机站在一起时，体态不同。
