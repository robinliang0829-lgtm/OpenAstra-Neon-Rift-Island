# NR-01 灰盒

给游戏组-虚幻引擎操作。这张卡只有一个要验收的动作。

**验证动作：** 打开仓库里的 `NeonRift.uproject`，按 `Content/Greybox/NR01_SteelTide.layout.json` 摆出钢潮港灰盒，并量出两侧出生点沿高架、沿机修巷走到中场的时间。

**通过：** 关卡里能找到下面列出的对象；四段步行时间已回传；附俯视、低机位、高机位各一张，镜头来自这次灰盒而不是概念图。高架约 8.0 秒，机修巷约 14.0 秒（600 uu/s，手计时允许 ±0.5 秒）。走不通的坡道写出坐标；没有就写「无」。

**停下，不要开工：** 只在本机没有 UE 安装路径时停下。把缺的引擎路径回给 PM-钢潮岛。文件里的 `EngineAssociation` `5.4` 是占位，真实小版本由 PM-钢潮岛按那台机器的安装锁定。不要另建工程，不要改用创世岛 Godot 或猎手岛工程，不要把 `.umap` / `.uasset` 交回这个仓，除非 PM-钢潮岛另说。

## 输入

- 工程：仓库根目录 `NeonRift.uproject`。分支 HEAD 见 `docs/BASELINE.md`
- 坐标：`Content/Greybox/NR01_SteelTide.layout.json`（由 `sim/steel_tide/layout.py` 从规则配置导出）
- 规则参数：`config/steel_tide_greybox.json`
- 资产：无成品网格。只用引擎基本体
- 参考：`docs/kickoff/refs/01_Neon_Bay.png` 只看海堤和机械轮廓，不按那张图给机器人分队

另外放这些块，名字保持一致：

- `NR_Deck_A`：X 0–2400，Y 0，宽 400，厚 40
- `NR_BridgeSpan`：X 2400–7200，Y 0，宽 400，厚 40。单独一块，以后可以藏起来。这张卡先留着，好让高架能走完

- `NR_AlleyDeck`：X 0–9600，Y 1800，宽 400，厚 40

- `NR_SeaWall`：挡在 Y < -200，避免量时间时走进海里
- 机修巷旁放几块名为 `NR_Cover` 的掩体。高架不放同等掩体
- 一个非碰撞的 `NR_Vista_SignalCore` 放在港区尽头当远景即可，不另做关卡

倒悬城市不用在这张卡里做。海水复位体积留给 NR-02。

## 参数

- 计量速度：600 uu/s，等于 `walk_speed_mps` 6。关掉冲刺再计时
- 高架出生 → 中场：48 米，约 8.0 秒
- 机修巷出生 → 中场：84 米，约 14.0 秒
- 两侧都量。A、B 应当对称
- 甲板碰撞要能站人。默认角色或一个胶囊体即可，英雄网格以后再换
- 米制：1 米 = 100 uu。轴向见配置文件里的 `ue_axes`

## 步骤

1. 用本机 UE 打开 `NeonRift.uproject`。若编辑器要求编译 NeonRift 模块，允许它编译。把实际引擎小版本和安装路径回给 PM-钢潮岛。小版本与 `5.4` 不一致时，先停，等 PM-钢潮岛改 `EngineAssociation`，不要自己另开工程。
2. 新建空关卡 `NR_SteelTide_Greybox`。出生点、端子、中场、高架和机修巷按布局 JSON 和上表放置。JSON 与上表不一致时以 JSON 为准，并把差异退回 Codex。
3. 用 600 uu/s 从 `NR_Spawn_A`、`NR_Spawn_B` 各走高架和机修巷到 `NR_CoreSpawn`，记下四段时间。
4. 截俯视、眼高约 160 uu 的低机位、以及约 1800 uu 的高机位，都从 A 侧看向中场。
5. 若有走不上去的坡，写出该物体的世界坐标。灰盒本身应当是平的。

## 画面目标

俯视能同时看见两处出生、两处端子、中场芯点和上下两线。低机位能从出生走到中场，不会掉出甲板。高架和机修巷一眼能分开。

## 回传

卡号 NR-01；工程路径；UE5 小版本；机器；分支与 SHA；四段时间；三张图的路径；走不通处的坐标或「无」。时间差得比 0.5 秒更多时，写你实际走过的路线，不要把端子挪去凑 8 秒。规则数字归 Codex。
