# Content

UE 操作员以后在这里放钢潮港的图和资产。这次开工没有 `.umap` 或 `.uasset`，也不要在没有工程路径时把二进制提交进来。

| 目录 | 以后放什么 |
| --- | --- |
| `Maps/SteelTide/` | `NR_SteelTide_Greybox` 以及以后的港口图 |
| `Greybox/` | NR-01 的块和体积，若工程选择单独目录 |
| `Characters/Human/` | 人类 |
| `Characters/Celestial/` | 天人 |
| `Characters/HumanoidRobot/` | 人形机器人，A/B 共用一套身体 |
| `Characters/Robot/` | 非人形机器人，含四足、履带、飞行器 |
| `Characters/Beast/` | 有机兽。不要把四足机放在这里 |
| `Decals/Badges/` | A 开口人字、B 闭合环 |
| `Materials/` | 湿混凝土、磨损黄漆等 |
| `Audio/BridgeWarning/` | 4 秒桥警报 |

`.umap` / `.uasset` 的作者是游戏组-虚幻引擎操作。Codex 不在这个目录写第二套规则。
